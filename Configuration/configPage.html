Watch Next

Every user gets their own Watch Next entry in the navigation drawer, holding two ordered lists — one for movies, one for shows — that they arrange by dragging. The top of each list is what they want to watch next. An entry disappears by itself once it has been watched: a movie when playback finishes or it is ticked off by hand, a show as soon as any one of its episodes is.

There is nothing to set up per user, and nothing here is required for the plugin to work. The settings below only affect how the drawer entry is presented.

Required: the File Transformation plugin by IAmParadox27, which is what lets this plugin place its entry in the navigation drawer. Jellyfin’s plugin catalogue has no concept of dependencies, so it has to be installed by hand: add https://www.iamparadox.dev/jellyfin/plugins/manifest.json as a plugin repository, install File Transformation, and restart Jellyfin. Without it the lists and the API still work, but no drawer entry appears.
